# IngéMaths

Site vitrine d’IngéMaths : accompagnement personnalisé en mathématiques et physique-chimie pour les élèves de Première et Terminale, préparation aux concours d’écoles d’ingénieurs et stages intensifs.

## Ouvrir le site

Le projet est un site statique. Ouvrez `index.html` dans un navigateur ou servez le dossier avec un serveur HTTP local.

## Structure

- `index.html` — contenu de la page
- `assets/css/` — styles et responsive design
- `assets/js/` — navigation mobile et interactions

## Personnalisation

Avant publication, remplacez le lien Calendly provisoire présent dans `index.html` par le lien définitif du compte IngéMaths.
